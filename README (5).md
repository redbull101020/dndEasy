# GPT D&D Campaign Runtime v3

Локальная папка для D&D 5e (2014/2024) в настольном ChatGPT. Это **свежая v3-схема**, без автоматической миграции сыгранной v2-кампании. Веб-проект без доступа к папке компьютера не подходит. Озвучка и автоматическое создание чатов не входят.

## Запуск

1. Распакуйте архив в отдельную общую локальную папку; не используйте архив как игровое хранилище.
2. Подключите папку как локальный проект в настольном ChatGPT и один раз вставьте содержимое `PROJECT_INSTRUCTIONS.md` в настройки проекта.
3. Убедитесь, что ChatGPT имеет доступ к локальному Python. Без Python нельзя безопасно играть, сохранять несколько файлов и бросать кубики.
4. В первом чате напишите «Давай начнём кампанию». Координатор согласует минимальные правила и даст промпт для нового чата лора; затем по очереди для персонажей и нарратива. Настройки кампании завершатся в первом чате.
5. После сообщения «Приключение можно начинать» откройте отдельный игровой чат и напишите «Начинаем приключение». Для следующего приключения вернитесь в чат нарратива, потом к координатору.

Только один чат одновременно записывает эту общую копию. Истинный этап подготовки — в `SAVE.md`, не в памяти переписки. Сюжетные файлы доступны всем, кто откроет папку.

## Где что находится

`CAMPAIGN.md` — правила и настройки; `LORE.md` (появится после мастерской) — устойчивый мир; `CAMPAIGN_STORY.md` (появится после мастерской) — гибкая общая арка; `adventures/####.md` — утверждённые приключения со структурированными разовыми наградами; `characters/<ID>.md` — полные актуальные листы героев с историей денег и выдач; `SAVE.md` — сцены, мир, этап, активное приключение и проверенные ссылки на листы. `workshops/` содержит инструкции и шаблоны. `tools/validate_runtime.py` проверяет структуру, `tools/state_commit.py` сохраняет броски до ответа и делает восстановимые согласованные записи, `tools/dice.py` — проверенный источник случайности. `transactions/` хранит roll, prepared переходы и pre-write копии. `journal/` и `backups/` — только история/recovery.

После изменения `PROJECT_INSTRUCTIONS.md` повторно вставьте его содержимое в настройки проекта: локальная проверка не видит текст внешнего поля. Для тестовой кампании используйте отдельную распакованную копию, а не основной шаблон.
