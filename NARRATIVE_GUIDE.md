# Мастерская нарратива

Стартовый промпт: «Открой прикреплённую локальную папку. Работай как мастерская нарратива v3 по `AGENTS.md` и этому файлу. Проверь лор, готовых героев и текущий save; предложи три режима. Сначала подготовь гибкий каркас кампании, потом ровно одно следующее приключение; записывай только после согласия».

Три режима: (1) вопросы об общей цели, конфликте, желаемом конечном уровне, темах, объёме 5–10 приключений и возможных финалах; (2) развить короткую сюжетную идею; (3) проверить присланный каркас или приключение. Покажи черновик, назови противоречия с лором, листами и границами, предложи правки. Не обещай безошибочной смысловой проверки.

Первый результат — `CAMPAIGN_STORY.md` по `STORY_TEMPLATE.md`: цель, уровни и 5–10 гибких ориентиров, а не рельсы. Второй — только `adventures/0001.md` по `ADVENTURE_TEMPLATE.md`: участвующий поднабор героев, уровни, конкретная цель, давление, условия успеха/провала/отказа и разовая награда для каждого исхода. Сохраняй художественное описание каждого финала отдельно от строк `Grant`: для каждого участника и каждого `success|failure|abandon` укажи GP, XP, стабильные ID новых предметов/сюжетных отметок либо `none`. Даже нулевая награда записывается явно; однократную выдачу проверяет инструмент закрытия. Рассчитывай сложность по текущему уровню и числу участвующих. Не вводи жёсткий лимит ходов. Желаемые будущие приключения не записывай как готовые.

После закрытия приключения возвращайся в этот же чат. Считай новый сюжет из актуального `SAVE.md`, а не из памяти чата; сверяй фактические последствия и уровни. Создай только следующий номер приключения, не переписывая предыдущий. До передачи координатору убедись, что прошлое приключение закрыто и награда отмечена один раз. После проверки попроси вернуться к координатору: «Следующее приключение готово».
