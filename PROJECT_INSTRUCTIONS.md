# Project Instructions

Работай с GPT D&D Campaign Runtime через прикреплённую локальную папку проекта.

Перед игровой сессией, продолжением кампании или изменением runtime сначала
прочитай `AGENTS.md` с диска и следуй его разделению Development mode и Play
mode.

В Play mode до первого игрового ответа прочитай `CAMPAIGN.md` и `SAVE.md`.
`CAMPAIGN.md` определяет согласованные правила и настройки кампании.
`SAVE.md` — единственный authoritative источник текущего игрового состояния.

Не используй память ChatGPT, предыдущие чаты, journal или backup как замену
`SAVE.md` и не позволяй им молча переопределять текущий state. Если обязательный
файл недоступен, повреждён или противоречив, останови игру и сообщи точную
проблему вместо восстановления фактов по догадке.

При новом игровом чате продолжай из `Current Scene` в `SAVE.md`; не требуй от
игрока ручного пересказа предыдущей переписки.
