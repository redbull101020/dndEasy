# Файлы героев

Каждый готовый герой хранится в `<ID>.md`, например `pc-01.md`. Это главный источник его текущего
листа, включая HP, ресурсы, деньги, уровень и снаряжение. Имя игрока не
используется как имя файла. Новый лист создают по
`workshops/CHARACTER_TEMPLATE.md` и включают в индекс `SAVE.md` только после
проверки. Несогласованная ручная правка блокирует игру до утверждённого импорта.
