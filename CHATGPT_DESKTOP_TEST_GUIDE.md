# Быстрый маршрут в настольном ChatGPT

1. Подключи **папку после распаковки**, не ZIP и не веб-проект. Один раз вставь весь `PROJECT_INSTRUCTIONS.md` в Project Instructions. Не включай одновременно два чата-writer для одной папки.
2. Первый чат: «Давай начнём кампанию». После согласования минимальных решений координатор даст стартовый текст для отдельной мастерской лора. Вставь его в новый чат этого же проекта.
3. Когда лор утверждён и файл создан, вернись в первый чат: «Лор готов». Повтори переход для персонажей: «Персонажи готовы», и нарратива: «Приключение готово».
4. Финально согласуй настройки. Только после фразы «Приключение 0001 можно начинать» открой **новый игровой чат**: «Начинаем приключение».
5. После финала вернись в чат нарратива и подготовь `0002`, затем в первый чат: «Следующее приключение готово». Новые настройки не нужны. После проверки и сообщения «можно начинать» открой новый игровой чат.

Точный приёмочный сценарий с проверкой трёх режимов, импорта, кубиков, переброса, rewards и второго приключения — в `ACCEPTANCE_TEST.md`. При ошибке validator игра останавливается; не восстанавливай потерянное состояние по памяти предыдущего чата.
