# Backups v3

Здесь могут лежать внешние snapshot **всей** кампании. Для безопасного восстановления одной пары `CAMPAIGN.md`/`SAVE.md` недостаточно: нужны `LORE.md`, `CAMPAIGN_STORY.md`, все `characters/`, `adventures/`, ledger и связанные hashes. Рабочие pre-write копии и статус каждого перехода лежат в `transactions/`. Не восстанавливай кампанию по памяти чата или одиночному файлу.
