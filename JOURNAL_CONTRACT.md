# Journal v3

`journal/` — необязательные исторические checkpoint'ы для чтения, не источник текущей истины. Новые записи создаются только после committed/PASS, с проверенным числовым именем; текст игрока не становится частью пути. Journal не должен дублировать authoritative листы персонажей как второе состояние. Для recovery используй transaction copies или согласованный snapshot всей папки, а не пересказ journal. Старые v2 journal-файлы не мигрируются автоматически в свежую v3-кампанию.
